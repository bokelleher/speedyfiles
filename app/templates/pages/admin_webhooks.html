Payload format

All events POST a JSON body like:

{
  "event": "package.finalized",
  "timestamp": "2026-05-13T20:30:22Z",
  "package_id": "abc123...",
  "title": "Demo masters — Acme",
  "recipient_email": "cust@acme.com",
  "owner_user_id": 1,
  "file_count": 3
}

Signature header (HMAC-SHA256 of raw body using the per-hook secret):

X-SpeedyFiles-Event: package.finalized
X-SpeedyFiles-Signature: sha256=<hex digest>
X-SpeedyFiles-Hook-Id: 42

After 10 consecutive failures the hook auto-disables. Click Enable to re-arm after fixing.
